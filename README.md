# University Management System

## Overview

The University Management System is a console-based application developed in C++ that simulates core academic administration operations within a university. The system manages students, professors, courses, enrollments, and grades through a structured Object-Oriented Programming approach.

The project demonstrates the practical application of OOP concepts, STL containers, file handling, and modular software design. It enables administrators to create and manage university records while maintaining persistent storage through text files.

---

## Key Features

### Student Management

* Add and manage student records
* View all registered students
* Search students using unique IDs

### Professor Management

* Add professors
* Assign professors to courses
* View professor details

### Course Management

* Create courses
* Manage course information
* View available courses

### Enrollment System

* Enroll students in courses
* Prevent duplicate enrollments
* Track student-course relationships

### Grade Management

* Assign grades to students
* Modify grades with professor authorization
* View academic performance records

### Persistent Data Storage

* Save records to files
* Load existing records at startup
* Maintain data consistency across sessions

## Project Structure

Student Class → Stores student information and course registrations

Professor Class → Manages professor information and course assignments

Course Class → Handles course details and enrolled students

University Class → Central controller for all university operations
